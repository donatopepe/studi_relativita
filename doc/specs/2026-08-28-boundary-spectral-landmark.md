# Boundary-induced spectral landmark gate

## Question

Can a spectral crossing generated by finite-region boundary terms identify `ell0`?

## Toy family

Use diagonal operator `R(ell)=diag(a ell^2 + beta, c ell^2)`, where `beta` represents declared boundary contribution. Crossing solves `a ell^2+beta=c ell^2`, hence `ell_cross=sqrt(beta/(c-a))` when ratio is positive.

This is algebraic toy control, not a derived GR boundary operator or UMCH mechanism.

## Counterexamples

- Free `beta` places crossing at arbitrary positive scale: `beta=(c-a) ell_cross^2`.
- No positive crossing when sign/domain condition fails.
- Common scalar multiplication preserves crossing, while channel-specific additive offsets move/create/remove it.
- If boundary coefficient is independently fixed by geometry/protocol, crossing identifies boundary/geometric scale only.
- `ell0` remains absent unless theory derives `ell_cross=alpha ell0` with fixed alpha and bounded nuisance.

## Decision

Status `BOUNDARY_SPECTRAL_LANDMARK_MOVABLE_NOT_ELL0`. Boundary terms can generate nonradial spectral flow and crossings but also create movable nuisance landmarks. No reformulation: physical boundary derivation and exact geometry remain open. `UNPROVEN`; `NO_POSITIVE_DETECTION_CLAIM`.
