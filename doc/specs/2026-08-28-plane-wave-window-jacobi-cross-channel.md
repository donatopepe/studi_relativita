# Exact plane-wave window/Jacobi cross-channel gate

## Question

For one exact plane-wave profile, does combining raw finite-window tidal operator `W(L)` with Jacobi vertex block `B(L)` make affine width or a universal scale identifiable after realistic gain/calibration nuisance?

## Designs

1. Compare unrelated channel summaries: rejected; no physical map.
2. Derive both channels from same exact `K(u)` on same interval (selected).
3. Claim profile width as `ell0`: rejected; no UMCH law.

## Derived channels

Use same canonical-sourced vacuum Brinkmann plane-wave profile and parallel screen as prior gate.

- Tidal window: `W(L)=int_{-L/2}^{L/2} K(u)du`.
- Jacobi vertex: solve `D''+K(u)D=0`, `D(-L/2)=0`, `D'(-L/2)=I`; set `B(L)=D(L/2)`.

This is a channel-native cross-map generated by same curvature history, affine interval, screen and boundary.

## Counterexample-first tests

- weak-profile expansion gives `B(L)=L I-int (L/2-u)(u+L/2)K(u)du+O(K^2)`; `B` is not a function of unweighted `W` alone;
- construct profiles with same `W` but different ordered/weighted history and show different `B`;
- fixed profile amplitudes and absolute affine normalization can make map `L -> (W,B)` locally injective on a preregistered bounded interval;
- free affine rescaling/profile-frequency nuisance produces equivalent dimensionless histories;
- independent channel gains erase absolute scale and can destroy injectivity after quotient;
- changing vertex boundary changes `B` without changing `W`;
- `ell0` absent.

## Interpretation

Shared exact geometry supplies physical cross-channel dependence, improving over arbitrary algebraic maps. It does not identify `ell0`: any inferred `L` is affine support width conditional on known profile, normalization, endpoint boundary and gains. No data, mechanism or detection.
