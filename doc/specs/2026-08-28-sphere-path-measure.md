## Exact extension

Let `D=diag(lambda1,lambda2)` at anchor on constant-curvature two-sphere. A normalized family of transport paths induces holonomy-angle probability measure `mu`. Average transported operator

`M_mu=int Q(alpha) D Q(alpha)^T dmu(alpha)`.

Write `m2=int exp(i 2 alpha)dmu(alpha)`. Exact eigenvalues are

`(lambda1+lambda2)/2 +- |lambda1-lambda2| |m2|/2`.

Thus spectrum depends only on magnitude of second circular moment. Full averaged matrix depends on complex `m2` after anchor frame fixed. All higher circular moments and path-distribution detail lie in null space. Distinct path measures with same `m2` produce identical matrix; measures with same `|m2|` produce conjugate/ispectral matrices. Isotropy occurs iff `m2=0`, generated by many measures. Deterministic single path has `|m2|=1`, preserving anisotropy.

On constant K sphere, alpha=K A modulo orientation/winding, so result translates to path-area measure. It contains no ell0.
