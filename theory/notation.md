# Notation and dimensions

Default metric signature: `(-,+,+,+)`. Alternative source conventions must be translated explicitly.

| Symbol | Meaning | Dimension |
|---|---|---|
| `c` | speed of light | `[c] = L T⁻¹` |
| `τ` | proper time | `T` |
| `x^μ` | spacetime coordinates | `L` (when `x⁰=ct`) |
| `u^μ` | four-velocity | `L T⁻¹` |
| `a^μ` | four-acceleration | `L T⁻²` |
| `κ` | candidate timelike worldline curvature | `L⁻¹` |
| `κ₀` | hypothesized universal minimum scale | `[κ₀] = L⁻¹` |
| `ℓ₀=κ₀⁻¹` | associated length scale | `L` |
| `G` | Newton constant | `L³ M⁻¹ T⁻²` |
| `ħ` | reduced Planck constant | `M L² T⁻¹` |
| `Λ` | cosmological constant | `L⁻²` |

SI dimensions are retained unless a derivation explicitly declares natural units. Factors of `c`, `ħ`, and `G` may not be restored by guesswork after a calculation.
