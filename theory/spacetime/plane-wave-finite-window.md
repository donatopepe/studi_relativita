# Exact plane-wave finite-window operator

Classification: `EXACT_SPACETIME_CONTROL_AND_NEGATIVE_IDENTIFIABILITY_RESULT`.

Status: `EXACT_PLANE_WAVE_FINITE_WINDOW_NONRADIAL_GEOMETRY_PROTOCOL_NOT_ELL0`; `NO_POSITIVE_DETECTION_CLAIM`.

Coley, McNutt and Milson (2012), DOI `10.1088/0264-9381/29/23/235023`, give exact vacuum plane waves in Brinkmann form with `f(zeta,u)=A(u)zeta^2` and relate curvature profile to geodesic deviation. Within this family choose declared tracefree transverse tidal operator in a parallel Brinkmann screen,

`K(u)=a(u)[[cos(2 theta(u)),sin(2 theta(u))],[sin(2 theta(u)),-cos(2 theta(u))]]`.

For centered affine top-hat window of width `L`, retain raw operator

`W(L)=int_{-L/2}^{L/2} K(u)du`.

Fixed polarization gives a projectively radial family. Odd linear polarization rotation around a centered symmetric window also collapses to a fixed projective direction because the off-diagonal integrand is odd. A profile with phase, amplitude gradient and nonlinear rotation produces nonzero projective distance between window widths: exact-spacetime curvature variation can therefore generate nonradial finite-window operator response.

This nonradiality does not identify `ell0`. Window center changes direction for the odd-rotation control, and replacing top-hat by triangular weighting changes direction for the asymmetric profile. Any zero, crossing or turnover is controlled by plane-wave profile, affine center, support and kernel. These are geometry/protocol scales unless an independent physical law links them to `ell/ell0`.

The source supports exact plane waves and curvature-driven deviation, not this window protocol, UMCH, a universal floor, `ell0` or detection. Numerical quadrature is deterministic. A physically selected causal window, endpoint screen certificate and cross-channel map remain open; no structural dead end or reformulation follows.
