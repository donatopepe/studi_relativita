# Boundary-induced spectral landmark

Classification: `TOY_CONTROL_AND_NEGATIVE_RESULT`.

Status: `BOUNDARY_SPECTRAL_LANDMARK_MOVABLE_NOT_ELL0`; `NO_POSITIVE_DETECTION_CLAIM`.

For diagonal toy operator

`R(ell)=diag(a ell^2+beta, c ell^2)`,

channel-specific additive boundary term creates nonradial spectral flow. Crossing exists at `ell_cross=sqrt(beta/(c-a))` only when ratio is positive. If `beta` is free, any positive target crossing is reproduced by `beta=(c-a)ell_cross^2`; crossing can also be removed by sign/domain choice. Thus landmark is movable boundary nuisance.

A common multiplicative amplitude would preserve crossing, but independent additive offsets move, create or remove it. If `beta`, `a`, `c` are independently derived from fixed geometry, boundary conditions and protocol, crossing estimates that geometric/boundary scale. It still does not estimate `ell0`, absent from family. UMCH requires derived relation `ell_cross=alpha ell0` with independently fixed `alpha` and bounded nuisance.

No physical GR boundary operator or observation is represented. No core reformulation is triggered; exact-geometry boundary maps remain open.
