# Holonomy orientation tomography

Classification: `PROJECT_DERIVATION_AND_NEGATIVE_RESULT`.

Status: `HOLONOMY_TOMOGRAPHY_RANK_CONDITIONAL_ELL0_ABSENT`; `NO_POSITIVE_DETECTION_CLAIM`.

For preregistered small-loop area-bivector orientations, use leading linearized record

`h = ell^2 M k`,

where `k` gives curvature-operator coordinates and `M` is orientation design matrix. If `rank(M)` is below curvature-coordinate dimension, its null space gives distinct operators with identical records. Full column rank recovers scaled operator `ell^2 k` in noiseless control.

Tomographic recovery is not universal-scale identification. Without independent curvature-amplitude information, transformation `ell -> alpha ell`, `k -> k/alpha^2` preserves record. Operational `ell` is normally known, so geometric curvature amplitude can be recovered; nevertheless `ell0` is absent from map. It enters only through separately derived theory-fixed landmark or response law.

Finite-loop path ordering, transport, boundary conditions, noise, orientation calibration and nuisance quotient remain outside leading control. No core reformulation is triggered.
