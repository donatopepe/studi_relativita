# Exact-pattern finite-window separability

Classification: `EXACT_PATTERN_CONTROL_AND_NEGATIVE_RESULT`.

Status: `EXACT_PATTERN_WINDOW_AVERAGING_REMAINS_PROJECTIVELY_RADIAL`; `NO_POSITIVE_DETECTION_CLAIM`.

In declared symmetry-reduced frames, FLRW tidal form `E(t)=k(t)I` and Schwarzschild radial principal form `E(r)=m r^-3 diag(-2,1,1)` are separable into scalar profile times fixed operator pattern. Any normalized scalar window average remains scalar times same pattern; subsequent `ell^2` normalization changes amplitude only. Different windows therefore remain on same projective ray while average is nonzero.

This supplies exact-pattern counterexample to claim that curvature amplitude variation across finite window is sufficient for nonradiality. A sign-changing average may cross zero, where projective direction is undefined, but zero location is profile/window-dependent and not an `ell0` landmark.

Nonradiality requires non-collinear patterns: symmetry breaking, transport mixing surviving conjugacy quotient, boundary terms, orientation structure, or physically derived cross-channel response. `ell0` is absent here.

Scope is scalar windows in fixed comoving/principal frames, not arbitrary spacetime regions. No new GR result or source claim is made. Nonsymmetric exact geometries remain open; no core reformulation is triggered.
