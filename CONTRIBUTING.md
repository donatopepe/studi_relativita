# Contribuire / Contributing

## Principi

Contributi in italiano o inglese sono benvenuti. Ogni contributo scientifico deve distinguere fatti noti, ipotesi, derivazioni, dati e congetture.

- Non presentare `κ₀ > 0` come risultato acquisito.
- Citare fonti primarie o revisioni autorevoli con URL canonico, DOI o arXiv verificato.
- Non inventare citazioni, dati, calcoli o risultati.
- Dichiarare assunzioni, unità, convenzioni e condizioni al contorno.
- Fornire codice e dati necessari alla riproduzione quando applicabile.
- Conservare risultati negativi e controesempi.
- Dichiarare assistenza IA materiale secondo `docs/ai-assistance.md`.

## Flusso

1. Aprire issue descrivendo claim, fonte o problema.
2. Creare branch dedicato.
3. Aggiungere o aggiornare test per tooling e artefatti verificabili.
4. Eseguire suite completa disponibile.
5. Aprire pull request con fonti, comandi di verifica e limiti.

Correzioni scientifiche devono indicare ID di claim/equazione interessati e motivare cambio di stato. Italiano e inglese devono restare semanticamente allineati.
