# Audit cross-channel del path di connessione nell'onda piana esatta

Classificazione: `EXACT_SPACETIME_CONNECTION_PATH_CROSS_CHANNEL_CONTROL_AND_NEGATIVE_IDENTIFIABILITY_RESULT`.

Stato: `EXACT_PLANE_WAVE_INTERNAL_SCREEN_CONNECTION_PATH_MOVES_TRANSPORTED_WINDOW_NOT_COVARIANT_ENDPOINT_MAPS_CROSS_CHANNEL_RANK_NOT_AUTOMATIC_NOT_ELL0`.

Gate aperto: `PHYSICAL_CONTINUOUS_SCREEN_READOUT_PATH_KERNEL_ENDPOINT_TETRADS_AND_ELL0_LAW_NOT_DERIVED`.

Gli oggetti raw `K,omega_1,omega_2,Q_1,Q_2,A_1,A_2,W_1,W_2,P_inertial,P_canonical,P_velocity,R,S_rot,S_0,L` restano primari. Due storie di connessione prescritte condividono esattamente `Q` e `A` agli endpoint, mentre i path interni di `Q` differiscono di `0.04595991799966836`.

Per `W_i=(1/L) int Q_i^T K Q_i du`, la differenza della finestra trasportata è `0.015157779434373101`; la differenza della mappa naive del profilo coniugato è `0.017400310040274355`. Le differenze della mappa covariante corretta `P_c=C_o^-1 P_inertial C_s`, della mappa di velocità `P_v=H(A_o)^-1 P_c H(A_s)`, del Sachs canonico `R` e del Sachs di velocità `S_rot=R-A_o` sono zero alla precisione riportata.

Quindi la mobilità del path interno dello screen prescritto non è automaticamente rango cross-channel indipendente. Uno screen campionato continuamente e derivato dal detector potrebbe restringere questo quoziente; qui non è derivato.

La covarianza common `SO(2)` passa; `O(2)` inverte la componente off-diagonal orientata con segno. Lo scaling affine/profilo/connessione/boundary a `s=1.47` ha residuo dimensionless massimo `3.95516952522712e-16`. Le caustiche restano un gate esplicito. Scala assoluta ed `ell0` non sono identificate.

Coley–McNutt–Milson 2012 supporta onde piane di Brinkmann vacuum esatte e deviazione geodetica guidata dalla curvatura, non path dello screen prescritti, finestre finite, calibrazione detector, indipendenza cross-channel, `ell0`, UMCH o detection.

Non è un vicolo cieco strutturale: readout fisico dello screen, tetradi, supporto/kernel causale, path di trasporto, standard endpoint e altre geometrie esatte restano aperti. UMCH `UNPROVEN`; `NO_POSITIVE_DETECTION_CLAIM`.
