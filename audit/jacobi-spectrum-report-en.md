# Null Jacobi spectrum audit

- Classification: `PROJECT_DERIVATION_AND_NEGATIVE_RESULT`
- Status: `JACOBI_CAUSTIC_GEOMETRIC_LANDMARK_NOT_ELL0`
- Detection: `NO_POSITIVE_DETECTION_CLAIM`

Constant diagonal optical-tidal control yields exact scalar Jacobi eigenmodes. Positive focusing has first caustic `pi/sqrt(lambda)`; zero and negative channels have no positive caustic in scope. Without fixed affine normalization there is `AFFINE_OPTICAL_SCALE_DEGENERACY`. With it, caustic locates geometric focusing scale, not `ell0`, which is absent from ODE. Sachs (1961), DOI `10.1098/rspa.1961.0202`, supports null-radiation context only, not UMCH or this normalization.
