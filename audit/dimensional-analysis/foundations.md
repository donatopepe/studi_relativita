# Foundational dimensional analysis

Conventions: `x⁰=ct`, proper time `τ`, metric signature `(-,+,+,+)`.

| Quantity | Dimension |
|---|---|
| `[x^μ]` | `L` |
| `[τ]` | `T` |
| `[u^μ]` | `L T⁻¹` |
| `[a^μ] = L T⁻²` | four-acceleration |
| `[κ] = L⁻¹` | candidate timelike curvature |
| `[κ₀]` | `L⁻¹` |
| `[N^μ]` | `1` |
| `[P^μ]` | `M L T⁻¹` |
| `[P^μP_μ] = M² L² T⁻²` | squared four-momentum |

## Identity

`a^μ=c²κN^μ` is dimensionally consistent because

\[
[c^2\kappa N^\mu]=(L^2T^{-2})(L^{-1})(1)=LT^{-2}=[a^\mu].
\]

`κ≥κ₀` is dimensionally well formed. Dimensional validity does not establish existence or positivity.

## Momentum norm

For `P^μ=m₀u^μ`, both sides of `P^μP_μ=-m₀²c²` have dimension `M²L²T⁻²`. Result requires constant rest mass and chosen signature.

## Caveats

Source typography collapses fractions and index placement. Normalized equations are editorial reconstructions linked to originals, not evidence that source derivations were correct. Natural-unit formulas in downstream modules require explicit unit declarations.
