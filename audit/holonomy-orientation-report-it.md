# Audit delle orientazioni di olonomia

- Classificazione: `PROJECT_DERIVATION_AND_NEGATIVE_RESULT`
- Stato: `HOLONOMY_TOMOGRAPHY_RANK_CONDITIONAL_ELL0_ABSENT`
- Detection: `NO_POSITIVE_DETECTION_CLAIM`

Nella linearizzazione leading per piccoli loop, la matrice delle orientazioni deve avere rango pieno sulle colonne per recuperare l'operatore di curvatura scalato. Un rango insufficiente produce collisioni esplicite. Anche la tomografia a rango pieno non contiene `ell0`: ricostruisce la geometria alla scala nota del loop, non un floor universale. Trasporto finite-loop, path ordering, boundary, calibrazione e nuisance restano irrisolti.
