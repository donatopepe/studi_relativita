# Audit della shape del path di olonomia

- Classificazione: `TOY_CONTROL_AND_NEGATIVE_RESULT`
- Stato: `HOLONOMY_TRACE_LANDMARK_PATH_SHAPE_MOVABLE_NOT_ELL0`
- Detection: `NO_POSITIVE_DETECTION_CLAIM`

Il crossing della traccia finite-loop sopravvive al similarity quotient ma dipende da un fattore libero di path shape. Tale fattore colloca il crossing a ogni scala positiva o lo rimuove. L'invarianza per coniugazione è necessaria, non sufficiente per l'identificabilità. Una loop family fissata dalla connessione darebbe soltanto scala geometrica/path; `ell0` resta assente.
