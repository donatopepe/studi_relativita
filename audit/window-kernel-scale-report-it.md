# Audit della scala del kernel di finestra

- Classificazione: `TOY_CONTROL_AND_NEGATIVE_RESULT`
- Stato: `FINITE_WINDOW_SPECTRAL_LANDMARK_KERNEL_DILATION_MOVABLE_NOT_ELL0`
- Detection: `NO_POSITIVE_DETECTION_CLAIM`

La media top-hat di `diag(1,s^2)` ha spettro nonradiale e isotropia a `ell=sqrt(3)/kappa`. La dilatazione libera del kernel colloca il crossing a ogni scala riportata positiva. Nella semilarghezza fisica `L=kappa ell`, il crossing è fisso, mostrando dipendenza dalla convenzione. Un kernel fissato dà solo geometria del profilo/finestra; `ell0` resta assente.
