# Falsification protocol

UMCH is research hypothesis, not protected conclusion. Tests must state sector, observable, dynamics, assumptions, units, uncertainty, and decision threshold before interpreting data.

## Rejection or restriction criteria

1. **Covariance failure:** proposed bound depends irreducibly on coordinates, arbitrary parametrization, frame, or gauge.
2. **Instability or inconsistency:** unavoidable instability, acausality, ghosts, ill-posed evolution, or incompatible constraints.
3. **Standard-limit failure:** established special/general-relativistic behavior is not recovered as `κ₀ → 0`, absent independently supported discontinuous physics.
4. **Observational exclusion:** all positive parameter space of a defined model conflicts with valid observational bounds.
5. **Sector contradiction:** timelike, null, field, or vacuum formulations sharing `κ₀` make mutually incompatible predictions.
6. **No new observable:** model is exactly equivalent to known theory and supplies no new observable consequence.
7. **Non-identifiability:** no experiment can map measured quantities to `κ₀` without arbitrary nuisance assumptions. This may reject only a proposed test, not automatically entire hypothesis.

## Protocol for a candidate test

1. Freeze equations and parameter definitions.
2. Derive observable and `κ₀→0` prediction.
3. Select published data and canonical source.
4. Declare uncertainty/systematic model and confidence rule.
5. Validate implementation on synthetic cases.
6. Run analysis once; preserve inputs and result.
7. Report bound, incompatibility, or `NO_BOUND_DERIVABLE`.
8. Record assumptions whose relaxation changes conclusion.

## Evidence discipline

Negative results remain public. `UNPROVEN` cannot be worded as established. A positive residual is not detection until alternatives, look-elsewhere effects, calibration, and independent replication are addressed.
